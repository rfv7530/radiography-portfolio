# Austin Lynden — Radiography Portfolio

Compiled visitor-facing deployment files for GitHub Pages. The portfolio is designed to be served at https://rfv7530.github.io/radiography-portfolio/.

Published content and authorised evidence are loaded from the separately hosted backend at https://radfolio-aqsqcxlu.manus.space. The private owner editor is available at https://radfolio-aqsqcxlu.manus.space/editor and requires owner authentication. Saving a draft does not publish it. Publishing content in the private editor updates the shared published data used by both sites.

This repository contains no private editor implementation, backend source, draft snapshots, CVs, credentials or private contact configuration. Its static page entry files support direct links and reloads. The backend allows anonymous Pages requests only for the published portfolio and public contact procedures.

Contact email delivery requires separate server-side email-service configuration. The site does not simulate successful sending when the email service is unavailable.

Source build: Manus canonical commit `1b4fd539804eb651b5b8d404780b031f6d7770e4`. Layout/navigation code changes require rebuilding and redeploying these compiled files; content changes published in the owner editor are fetched live.
